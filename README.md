# Gloria

Mobile-first test-marketing landing page for Gloria, a desktop hologram AI assistant.

## GitHub Pages

This repository is intentionally static and self-contained.

1. Keep `index.html`, `gloria-device.webp`, `.nojekyll`, and this `README.md` in the root of `main`.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then **Save**.

No API keys, credentials, or backend secrets belong in this repository.
