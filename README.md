# Gloria

Mobile-first launch page for Gloria, a hologram-style AI companion. The US launch collection contains only the 6-inch, 10.1-inch and 21.5-inch Android configurations.

## GitHub Pages

This repository is intentionally static and self-contained.

1. Keep `index.html`, `styles.css`, `assets/`, `brochures/`, `.nojekyll`, and this `README.md` on `main`.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then **Save**.

No API keys, credentials, or backend secrets belong in this repository.

## Launch state

Orders are not open. No payments or personal data are collected. The former prototype-only pricing/sign-up form and decorative permission toggles have been replaced with product information and working brochure downloads. Do not present the previous test prices as approved retail prices for the three-model collection.

Before linking checkout, confirm retail prices, included AI service/usage, actual inventory, fulfillment and returns, model-specific photos and the approved TikTok Shop URLs. Connected-service examples describe product direction, not a promise that every integration is currently available.

## Product sources

Specifications use columns D (6-inch Android), G (10.1-inch Android) and I (21.5-inch Android), including their merged shared cells, from the supplier's 2026 Hologram Cylinder Price List. The 6-inch standard configuration has 2 GB RAM (4 GB optional), not 4 GB by default. Do not put supplier costs or the wholesale price list in this public repository.

The hero uses the approved visualization with the avatar blending into black. Both approved 21.5-inch brochures are included. The legacy `gloria-device.webp` is retained but unused.

## Validation

This is a buildless static site. Verify relative asset/PDF paths, unique IDs, in-page links and CSS syntax before merging. No JavaScript or third-party runtime dependencies are required.
